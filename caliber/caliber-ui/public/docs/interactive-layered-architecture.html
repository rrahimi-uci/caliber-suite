Interactive layered architecture

A guided, click-to-focus view of the repository-level architecture. Use it to inspect how the six stack layers, the shared platform services, and the governed-asset tiers relate without scanning the full static diagram at once.

Why this view exists

The static layered architecture page is the authoritative source. This interactive explorer is the presentation-grade companion: it keeps the same model, but lets you isolate one layer, one path, or one node at a time.

Inspect one concern Filter to one layer family to cut visual noise without losing the surrounding topology.
Trace one path Highlight prompt delivery, workflow deployment, observability, or integration routes end to end.
Keep the stack readable The layout stays explicitly layered rather than relying on auto-layout heuristics.

How to use it

  • Click any node to see what it owns, where it fits, and which docs page explains it in depth.
  • Use the Layer focus chips to show only one part of the system.
  • Use the Guided paths chips to trace one scenario through the stack.
  • Drag the canvas to pan. Use the mouse wheel or the zoom controls to inspect dense areas.
