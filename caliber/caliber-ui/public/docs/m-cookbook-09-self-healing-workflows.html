Cookbook 09 · Operate

Self-Healing Workflows

Reproduce production failures, read the run debugger and trace, write the patch as a new version, prove it on the same 35 tickets, and roll an alias back.

OperateCore20–30 min
What you build. A refund-intake workflow (start, validate, check_reference, lookup, decide, final) that is fine on the tickets you tested and fails on the ones production sends. Version 1 completes 11 of 35 tickets and fails 24, in three nodes for three reasons: a schema violation in validate, a poison record that makes check_reference time out, and an account-service error that fails decide two steps after lookup. You write the patch yourself (three node bodies, saved as version 2) and rerun all 35. No model is involved (no agent node) and the account service is a stand-in, assets/upstream/account_service.py.
Surfaces: Workflows Run Monitor Versions Observability
What you learn
  • Reproduce a schema failure (F12), a poison record (F29) and an upstream failure (F32), which all show the same failed badge, and find the node in Recovery Diagnostics (Current node), Execution Debugger and the error trace
  • See that a node failure leaves no checkpoint (only approvals and waits do) and that Retry (Attempt 2 of 2) fails at the same node: a retry is not a fix for a code fault
  • Call propose-patch and see its limits: a generic prompt suggestion for the timed-out node and a 400 for a guardrail patch aimed at a code node; the CALIBER Patches tab stays empty
  • Write version 2 by hand (assets/workflow/patch/validate.py, check_reference.py, decide.py), prove it on all 35 tickets, and compare versions in Versions
  • Move the staging alias to version 2, run through it, roll back, and see prod refuse a version with no deploy gate

Implementation flow

flowchart LR
  R[Run 35 tickets on v1] --> F[24 failed, 11 completed]
  F --> D[Recovery Diagnostics, Execution Debugger, trace]
  D --> RC[Root cause node: validate, check_reference or decide]
  RC --> RT[Retry: Attempt 2 of 2 fails at same node]
  RT --> PP[propose-patch: no code fix]
  PP --> P[Edit 3 node bodies, save and publish v2]
  P --> V[Run 35 tickets on v2: 0 failed]
  V --> A[staging alias to v2, rollback restores v1]
  A --> PR[prod refuses: no deploy gate]

          raw = input if input is not None else run_input
          ticket = json.loads(raw) if isinstance(raw, str) else raw
          if not isinstance(ticket, dict):
              raise ValueError("ticket must be a JSON object")
          for key in ("ticket_id", "account_id", "amount", "currency", "reason", "order_ref"):
              if key not in ticket:
                  raise ValueError("missing required field '" + key + "'")
          amount = ticket["amount"]
          if isinstance(amount, bool) or not isinstance(amount, (int, float)):
              raise ValueError("amount must be a number, got " + repr(amount))
          if amount <= 0:
              raise ValueError("amount must be greater than 0, got " + repr(amount))
          if ticket["currency"] not in ("USD", "EUR", "GBP"):
              raise ValueError("unsupported currency " + repr(ticket["currency"]))
          if not re.match(r"^A-[0-9]{4}$", str(ticket["account_id"])):
              raise ValueError("account_id must look like A-1234, got " + repr(ticket["account_id"]))
          if not str(ticket["reason"]).strip():
              raise ValueError("reason must not be empty")
          ticket["ok"] = True
          return ticket

          ticket["reference_valid"] = bool(ORDER_REF.match(str(ticket.get("order_ref") or "")))
          ticket["query"] = {"account_id": ticket.get("account_id")}

assets/workflow/patch/validate.py 
CURRENCIES = {"USD": "USD", "EUR": "EUR", "GBP": "GBP", "$": "USD", "\u20ac": "EUR", "\u00a3": "GBP"}

def _amount(value):
    if isinstance(value, bool):
        return None, "amount must be a number, got " + repr(value)
    if isinstance(value, (int, float)):
        return value, None
    if isinstance(value, str):
        text = value.strip()
        for symbol in ("$", "\u20ac", "\u00a3", "USD", "EUR", "GBP"):
            text = text.replace(symbol, "")
        text = text.strip()
        if re.match(r"^[0-9]+,[0-9]{1,2}$", text):
            return None, "amount " + repr(value) + " is ambiguous: comma may be a decimal separator"
        text = text.replace(",", "")
        if re.match(r"^[0-9]+(\.[0-9]+)?$", text):
            return (float(text) if "." in text else int(text)), None
    return None, "amount must be a number, got " + repr(value)

def run_python_node(input=None, context=None, inputs=None, run_input=''):
    raw = input if input is not None else run_input
    errors = []
    try:
        ticket = json.loads(raw) if isinstance(raw, str) else raw
    except Exception:
        return {"ok": False, "errors": ["ticket is not valid JSON"]}
    if not isinstance(ticket, dict):
        return {"ok": False, "errors": ["ticket must be a JSON object"]}
    for key in ("ticket_id", "account_id", "amount", "currency", "reason", "order_ref"):
        if key not in ticket:
            errors.append("missing required field '" + key + "'")
    out = {"ticket_id": ticket.get("ticket_id")}
    if "account_id" in ticket:
        account_id = str(ticket["account_id"]).strip().upper()
        if not re.match(r"^A-[0-9]{4}$", account_id):
            errors.append("account_id must look like A-1234, got " + repr(ticket["account_id"]))
        out["account_id"] = account_id
    if "amount" in ticket:
        amount, problem = _amount(ticket["amount"])
        if problem:
            errors.append(problem)
        elif amount <= 0:
            errors.append("amount must be greater than 0, got " + repr(ticket["amount"]))
        out["amount"] = amount
    if "currency" in ticket:
        currency = CURRENCIES.get(str(ticket["currency"]).strip().upper()) or CURRENCIES.get(str(ticket["currency"]).strip())
        if currency is None:
            errors.append("unsupported currency " + repr(ticket["currency"]))
        out["currency"] = currency
    if "reason" in ticket:
        if not str(ticket["reason"]).strip():
            errors.append("reason must not be empty")
        out["reason"] = str(ticket["reason"]).strip()
    if "order_ref" in ticket:
        out["order_ref"] = str(ticket["order_ref"]).strip()
    out["ok"] = not errors
    if errors:
        out["errors"] = errors
    return out

  • Prerequisite flags. The lab itself needs none: workflows, the Run Monitor, versions and aliases are part of the supported alpha. CALIBER_FEATURE_COOKBOOKS=true only opens the gallery, whose starter this lab does not use. Aria is not used.

  • Patching is manual. propose-patch is API only, agent-shaped (it cannot repair a code node) and no page calls it. Aria is not used and there is no UI for aliases: the alpha UI has one live alias (prod), so staging and its rollback are API only.
