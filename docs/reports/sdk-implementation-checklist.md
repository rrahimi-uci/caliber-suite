# CALIBER SDK Implementation Checklist

Companion to [sdk-detailed-plan.md](../../docs/reports/sdk-detailed-plan.md).

This file is the execution checklist for the SDK plan. It is organized as milestone gates and PR-sized work items so implementation can move in a controlled order without the SDK outrunning the backend contract.

## How to use this checklist

- Treat each PR item as one reviewable branch or PR.
- Do not mark a milestone complete until its validation commands pass and its exit gate is satisfied.
- Do not start a downstream milestone if its dependency milestone is still open.
- Keep platform gaps explicit. If the backend does not support a capability yet, track that as a backend blocker instead of hiding it in the SDK.

## Status legend

- `[ ]` not started
- `[~]` in progress
- `[x]` complete
- `[!]` blocked by backend/platform decision

### M0-PR4 — Personal Access Tokens for automation

Scope:

- [x] add PAT data model and migration
- [x] add PAT issuance/list/revoke/rotate endpoints
- [x] add scope enforcement and audit coverage
- [ ] document CSRF interaction for SDK login/bootstrap flows

Delivered: `caliber_personal_access_tokens` (migration 0086), issuance/list/
revoke/rotate under `/auth/tokens`, and PAT resolution in the auth chain. Only
the SHA-256 digest is stored; the plaintext is returned exactly once. A token's
scopes are a **ceiling** intersected with its owner's current authority, so it
cannot grant what the owner lacks and a demotion narrows every token they own
immediately. Another user's token is 404, not 403, so ids cannot be enumerated.

Primary code targets:

- [caliber/src/caliber/auth.py](../../caliber/src/caliber/auth.py)
- [caliber/src/caliber/routes/auth.py](../../caliber/src/caliber/routes/auth.py)
- [caliber/src/caliber/routes/csrf.py](../../caliber/src/caliber/routes/csrf.py)
- new DB migration under `caliber/src/caliber/db/migrations/versions/`

Validation:

- [x] added `caliber/tests/test_personal_access_tokens.py` (19 tests)

- [ ] `pytest caliber/tests/test_auth.py caliber/tests/test_auth_sessions.py caliber/tests/test_auth_scopes.py caliber/tests/test_auth_csrf_composition.py`
