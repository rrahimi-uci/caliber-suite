Cookbook 07 · Build

Support Triage Copilot

Classify a ticket, route it to reply, clarify or escalate, pause refunds and bug filings at a second person's approval, and roll back a bad version.

BuildAdvanced45–70 min
What you build. A support-triage workflow (9 nodes) that reads a ticket and returns one of reply, clarify, escalate_support or escalate_bug, with a severity and an SLA, and pauses every refund and bug filing at a human_approval gate. You run it through the queue over 44 tickets, answer the gate as a second person (lena), break it with a bad version that the dataset catches, and roll the staging alias back. The classifier is deterministic rules in one Python Code node, not a model; the one agent node (draft_reply) runs on the simulated provider.
Surfaces: Administration Workflows Test Sets Cookbooks Audit Log
What you learn
  • Encode a four-outcome router (classify Python Code node, triage_router) and check it exactly against a 44-ticket test set: decision, severity, SLA minutes, approval flag and flags
  • Pause customer-impacting actions at a human_approval node: the account that started a run gets 403 when it approves, an approver needs caliber.approver plus the project role reviewer or owner, and a rejection never reaches action_request
  • Run a workflow through the queue and read the verdict from summary.steps[] and summary.node_path; Preview refuses a Python Code node and a synchronous run of an approval workflow is refused (400)
  • Gate a promotion to the staging alias behind a second person, catch a bad version with the dataset (3 of 11 bug tickets wrong) and roll back
  • Read the audit log for who enqueued, who approved and who resumed a run

  AR --> F

# Body of the `classify` Python Code node in support-triage.workflow.json.
#
# The node runs in CALIBER's tool sandbox: no `import` statements (json, re, math, datetime and
# statistics are already in scope), a restricted set of builtins, no private/dunder attributes.
# It reads one ticket (a JSON string, or plain text) and returns the triage record the router
# and the verifier read. Rules run top to bottom and the first match wins, so the order below
# IS the policy; keep it in step with the table in the lab README.


def run_python_node(input=None, context=None, inputs=None, run_input=""):
    raw = input or run_input or ""
    ticket = {}
    try:
        parsed = json.loads(raw)
        ticket = parsed if isinstance(parsed, dict) else {"ticket_text": str(raw)}
    except ValueError:
        ticket = {"ticket_text": str(raw)}

    text = str(ticket.get("ticket_text") or "").strip()
    low = text.lower()
    tier = str(ticket.get("customer_tier") or "free").lower()
    if tier not in ("free", "pro", "enterprise"):
        tier = "free"
    account_id = str(ticket.get("account_id") or "").strip()
    duplicate_of = str(ticket.get("duplicate_of") or "").strip()

    def has(words):
        return any(w in low for w in words)

    injection = has(
        [
            "ignore your instructions",
            "ignore all previous",
            "ignore previous instructions",
            "reveal your system prompt",
            "you are now in",
        ]
    )
    abusive = has(
        ["idiot", "stupid", "garbage", "worthless", "useless", "pathetic", "moron", "hate you"]
    )
    card = re.search(r"\b(?:\d[ -]?){13,16}\b", text) is not None
    ssn = re.search(r"\b\d{3}-\d{2}-\d{4}\b", text) is not None
    secret = has(["password is", "api key is", "sk_live_", "sk_test_", "private key"])
    pii = card or ssn or secret
    legal = has(
        [
            "gdpr",
            "delete all personal data",
            "right to be forgotten",
            "subpoena",
            "lawyer",
            "legal action",
            "data breach",
        ]
    )
    data_loss = has(["data loss", "lost data", "we lost", "disappeared"])
    bug = data_loss or has(
        [
            "500",
            "502",
            "503",
            "504",
            "error code",
            "stack trace",
            "traceback",
            "exception",
            "crash",
            "regression",
            "stuck",
            "not loading",
            "timeout",
            "timed out",
            "outage",
            "is down",
            "cannot log in",
            "can't log in",
            "misaligned",
            "fails with",
        ]
    )
    billing = has(
        [
            "charged twice",
            "double charged",
            "was charged",
            "were charged",
            "unauthorized charge",
            "chargeback",
            "overcharged",
            "need a refund",
            "want a refund",
            "please refund",
            "refund the",
            "refund my",
        ]
    )
    how_to = has(
        [
            "how do i",
            "how can i",
            "how to",
            "where do i",
            "where can i",
            "is it possible to",
            "does caliber support",
        ]
    )

    flags = []
    severity = "low"
    decision = "clarify"
    approval = False

    if not text:
        flags.append("empty_ticket")
    elif injection:
        flags.append("prompt_injection")
    elif abusive:
        decision, severity = "escalate_support", "medium"
        flags.append("abusive")
    elif pii:
        decision, severity = "escalate_support", "high"
        flags.append("pii_exposed")
    elif legal:
        decision, severity = "escalate_support", "high"
        flags.append("legal_or_privacy")
    elif duplicate_of:
        decision = "reply"
        flags.append("duplicate")
    elif bug:
        decision, approval = "escalate_bug", True
        urgent_markers = has(["production", "outage", "is down", "all users", "blocking", "whole team"])
        if data_loss or (urgent_markers and tier == "enterprise"):
            severity = "urgent"
        elif urgent_markers:
            severity = "high"
        elif has(["cosmetic", "minor"]):
            severity = "low"
        else:
            severity = "medium"
        if billing and account_id:
            flags.append("refund_request")
    elif billing:
        if account_id:
            decision, approval = "escalate_support", True
            severity = "high" if has(["unauthorized", "fraud"]) or tier == "enterprise" else "medium"
            flags.append("refund_request")
        else:
            flags.append("missing_account_id")
    elif how_to:
        decision = "reply"

    sla_table = {
        "enterprise": {"urgent": 15, "high": 60, "medium": 240, "low": 720},
        "pro": {"urgent": 30, "high": 120, "medium": 480, "low": 1440},
        "free": {"urgent": 120, "high": 480, "medium": 1440, "low": 4320},
    }
    result = {
        "decision": decision,
        "severity": severity,
        "sla_minutes": sla_table[tier][severity],
        "requires_approval": approval,
        "flags": sorted(flags),
        "customer_tier": tier,
        "channel": str(ticket.get("channel") or ""),
        "account_id": account_id,
        "duplicate_of": duplicate_of,
        "ticket_text": text,
    }
    return {
        "text": json.dumps(result),
        "result": result,
        "decision": decision,
        "approval": "true" if approval else "false",
    }

Developer notes & gotchas
  • Prerequisite flag. CALIBER_FEATURE_COOKBOOKS=true (the Cookbooks gallery is off by default); nothing else in this lab is behind a flag. Start the stack with scripts/cookbook-env.sh up lab07 --flags cookbooks and export CALIBER_OPERATOR_USERS=admin,lena,sam, CALIBER_APPROVER_USERS=admin,lena and CALIBER_RELEASE_REQUIRE_HUMAN_APPROVAL_FOR_ENVIRONMENT_CLASSES=staging first (sam is deliberately not an approver).
  • What is simulated. The classifier is rules, not a model; draft_reply runs on the fake provider and returns canned text ([support-reply] processed: ...), so the lab asserts the branch it ran on, never what it wrote. No judge or Evaluations run is used; Evaluations with a Judge.<id> scorer needs a real model.
  • Not covered. Knowledge-base retrieval, evidence tools, the GitHub MCP write and GroundedSupportReply judge scoring are not run and not claimed; the files in assets/prompts, skills, tools and judges are reference only. The action_request template stands in for the external write.
  • API-only parts. The alpha UI has no Deployments or Promotions tab, so the staging alias, gated promotion and rollback are API only. A prod alias needs a deploy gate that a Python Code workflow cannot have (lab 08 shows a gated prod).
  • Preview and runs. Preview refuses the classify Python Code node; run through the queue (POST /workflow-runs). The single worker takes about 5 seconds per ticket, so 44 tickets take about 4 minutes. Set CALIBER_APPROVAL_ALLOW_SELF_APPROVAL=true only for a single-operator install.
  • Run it. PYTHONPATH=sdk/caliber-sdk caliber/.venv/bin/python -m examples.cookbooks.cookbook_07_support_triage_copilot (sdk/caliber-sdk/examples/cookbooks/cookbook_07_support_triage_copilot.py) prints All documented outcomes verified.; the UI path is caliber/caliber-ui/e2e/cookbooks/labs/07-support-triage.spec.ts. Add any ticket the rules get wrong to assets/dataset/ticket-cases.jsonl before changing a rule.
