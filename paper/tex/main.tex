\section*{Availability}
\label{sec:availability}
\addcontentsline{toc}{section}{Availability}
\sys is released under the Apache~2.0 license. The implementation identifier
\code{\statGitRev} records the base revision used for every count in
\secref{sec:impl}; the \code{-dirty} suffix explicitly means those counts include
working-tree changes. The manuscript source, generated counts, and build
instructions are under \code{paper/} in the working tree supplied for review.

One artifact boundary is intentionally explicit: \textbf{the inspected checkout
does not yet track \code{paper/} in Git}. A release artifact must add it and record
the resulting commit before claiming that source and implementation are versioned
together. What can be reproduced from the current working tree is the document and
its source-derived counts. Running \code{make repro} in \code{paper/} regenerates
\code{generated/stats.tex}, forces a four-pass build, and runs the document checks.
\code{paper/REPRODUCE.md} records the required toolchain and the boundary of that
command.

What that does \emph{not} establish is the measurement protocol, which needs a
pinned environment we have not yet published, and which is the first thing to add
once \tabref{tab:results} has numbers in it.
