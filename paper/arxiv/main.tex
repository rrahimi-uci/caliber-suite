\section*{Availability}
\label{sec:availability}
\sys is released under the Apache~2.0 license. The implementation identifier
\code{\statGitRev} records the base revision used for every count in
\secref{sec:impl}; the \code{-dirty} suffix explicitly means those counts include
working-tree changes. The manuscript source, generated counts, and build
instructions are included in this arXiv source package.

The manuscript source is versioned in the same repository as the implementation it
describes, so a reader can check the paper against one disclosed source state. In a
dirty checkout, the base revision alone does not identify the uncommitted patch;
the \code{-dirty} marker is a disclosure, not a reproducibility claim.
What can be reproduced is the document and its source-derived counts: running
\code{make} in this directory rebuilds the PDF from the bundled sources and
generated counts. The unrun performance, scale, baseline, and human-study protocol
remain future work exactly as \tabref{tab:results} and \secref{sec:limitations}
state.
